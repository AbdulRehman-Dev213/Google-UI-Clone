# 🔍 Google UI Clone

## 🌟 Project Overview
This project is a **frontend clone of the Google homepage**, built using **HTML and CSS**.  
The goal of this project was to practice real-world UI structuring, layout design, and positioning techniques used in modern web development.

---

## 🎯 Purpose of This Project
- Strengthen core HTML & CSS fundamentals  
- Improve layout design and visual structuring skills  
- Practice cloning real-world user interfaces  
- Understand spacing, alignment, and responsiveness basics  

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  

---

## ✨ Key Features
- 🔎 Google-style search layout  
- 🎯 Pixel-aligned UI structure  
- 🧭 Proper header, search bar, and button alignment  
- 🎨 Clean and minimal design approach  
- 💡 Hover effects for interactive elements  
- 📱 Basic responsive structure (if implemented)
