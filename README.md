# Google Homepage UI Clone

A frontend recreation of the Google homepage built using HTML and CSS. This project focuses on replicating the layout, spacing, and visual appearance of Google's search page while strengthening core frontend development skills. The goal was to practice real-world UI cloning and improve attention to design details.

## Features

* Google homepage inspired design
* Clean and minimal user interface
* Top navigation bar with Gmail and Images links
* Interactive menu and profile icon section
* Search bar with search, microphone, and camera icons
* Custom shortcut card section
* Hover effects for interactive elements
* Flexible layout using CSS Flexbox
* Responsive structure foundation
* Pixel-perfect UI replication practice

## Tech Stack

* HTML5
* CSS3
* Flexbox
* Custom Images & Icons

## Skills Learned

Through this project, I practiced and improved:

* Structuring web pages with semantic HTML
* CSS Flexbox for layout management
* Positioning and alignment techniques
* Creating navigation bars
* Building search interface layouts
* Working with images and icons
* Hover effects and UI interactions
* Replicating real-world website designs
* Improving attention to spacing and visual consistency

* Maintaining visual balance across different sections
